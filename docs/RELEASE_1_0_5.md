# 1.0.5 统一标签与禁用光标修复

分支：`test`。

## 结果行为

- 事项类型、环境及等级不再作为独立必填分类字段参与生成、编辑、筛选或合并判断。普通事项与定时模板都编辑同一 `tags` 数组；所有当前目录中的类型均能找到编辑入口，没有依据时可为空。
- 新目录只初始化事项类型与事项等级，初始值可增删、改名或重排，不初始化环境类型，不补“未指定／不适用”。旧字段仅保留为输入和历史兼容读取：首次升级转为真实标签并清空旧字段；历史报表和审计不重写。转换有标记，删除预设后重启不会重建。
- 按用户确认保留等级排序及临近截止自动提级，改为读取当前版本的 `priority_kind` 和该组 values 的高到低顺序。等级组或值改名保留排序位置，重排改变排序；自动提级是展示与排序投影，不覆盖人工保存的等级。删除整个等级组后停止该组提级与排序，不重建默认值。
- AI 标签建议仍经既有确认流程采用；归档维护支持新增、删除、改名、整组改名／删除及顺序调整。目录删除或改名同步当前事项、定时模板及筛选，保存赋值变化和版本历史。回滚在赋值仍匹配时恢复，后续独立修改不被旧历史覆盖。
- 普通禁用按钮使用默认鼠标光标，仅明确 `aria-busy=true` 的执行中按钮显示等待光标；不改变工作时段或加班权限。
- 原生启动就绪检查读取动态标签目录，不再写死事项类型数量。

## 数据与验证边界

不修改运行中的安装、真实事项或个人提示词。只更新公开默认规则和与本版 schema 一致的标签协议；用户已保存的个人规则保持原样。新协议只接受 tags 和受约束的目录变更，不授权执行事项或扩张工具访问。

离线测试使用合成消息、标签与模拟 AI/ACP。安装升级测试使用隔离目录，检查旧分类转换、占位值清理、真实分类保留及配置、本地提示词、日志、报表、插件文件保留。Mica 透明背景浅底问题 SS-059 仍是独立待办，本版不宣称修复；原生 smoke 的不透明模式不能代表真实 Mica 已验证。
