# 1.2.1 更新说明

本次更新完善事项处置、数据管理、界面阅读和后台保存，升级保留已有数据与个人配置。

- Codex 处置由桌面会话执行，拾事同步公开进度、工具记录、输入、等待状态和结论。结束处置只停止拾事同步，桌面任务继续运行；发送结果不确定时不自动重发。分析与归档继续使用各自的既有接入。
- 数据目录可选择复制迁移、直接切换或取消。迁移助手等待原进程退出，按字节复制并回读校验，完成后保存新位置并重启；原目录保留，失败不提交新位置。隐藏 AI 工作目录入口，保留已有配置。
- 事项使用持久编号，删除后不复用；可搜索、排序和分页查看变更记录。系统日志支持模糊搜索，先过滤再分页。
- 描述、消息依据与变更记录分区显示；没有依据时不可展开。长内容展开收起保留阅读位置，底部收起操作保持可见，连续滚动可衔接主界面。修复编辑接入时拖选到外部被误收起的问题，收紧设置和关于页布局。
- 自动更新默认开启，下载后及安装前核验来源、大小和 SHA-256。09:00 提醒已校验的新包，04:00 独立安装并重启；错过时点不补执行，可关闭开关，手动操作仍保留。升级保留数据位置、配置和快捷方式选择。版本旁的编译时间在打包时自动生成。
- 归档可从本批操作记录整理私有长期经验，无需先填归档备注；继续校验冻结来源、长度和并发版本，不修改临时记忆、用户提示词或行为规则。
- 状态变更先保存再发布；日志由专用线程按有界队列写入，查询、迁移和正常退出前排空。运行态快照与临时流式预览减少重复处理，生命周期、审批、用量和最终结果仍立即保存。意外退出可能丢失上次业务保存之后的末段预览。
- 子进程输出、排空、取消和超时保持大小限制；更新缓存只回收可确认属于更新器且超过保留时间的内容，保护当前包、占用中的助手和未知文件。构建记录实际 WebView2 加载器版本、摘要及产物体积。

离线回归使用合成数据和模拟接口；原生验证使用全新隔离目录。Codex 桌面消息通道属于内部接口，升级桌面后需复核兼容性；本次不以模拟回归代替真实模型验证，也不承诺固定提速或缩包比例。
