# 1.0.1 变更与验证

维护分支：test。发布包由最终同一份源码构建，不包含运行数据、私人插件或凭据。

## 功能

- 顶部直接启停定时扫描增量消息；扫描暂停时早晚报和下班归档继续调度，自动分析由独立开关控制。设置中扫描、分析改用开关，消息过滤紧随扫描。
- 设置和 AI 接入按实际差异提示保存；连接未修改时失焦自动收起，已有连接展开只查看，刷新模型才读取。
- 本地接入检测确定候选后读取模型并自动保存，保持用途独立；同名模型显示来源，保留完整路由。
- API 接入类型完整显示 OpenAI Chat Completions 兼容 API。
- 单请求补查默认累计 60,000 字符且可配置；覆盖不足归档拒绝采用结果，保留未处理进度。

## 数据与工程

- 不兼容数据经确认后先备份并校验，再清理活动文件。完好的正式文件不被中断临时文件阻断；有效恢复候选不静默丢弃。
- 调度保存失败在原 120 秒窗口内重试，超窗提示手动处理。归档与调度历史保留 90 天，并保护当前版本、必要引用及未完成任务。
- 状态流式保存、归档提示词内容引用去重、快照构建与序列化移出全局锁、事项审计索引复用。
- 前端源码按 assets/ui/scripts/styles 拆分，统一构建为嵌入 HTML；合并旧样式覆盖，后端通知版本变化并合并按页刷新，移除固定全量轮询。
- DSH 检测路径和版本索引归一，批处理启动隔离参数、关闭回显与延迟扩展，保留严格 ACP 协议校验及分阶段错误。

## 验证

- Rust 工作区：396 项通过，7 项按既有边界忽略；不调用真实模型。
- 11 套 UI 回归全部通过，包含新增状态同步回归；窄屏布局及截图检查通过。
- 虚拟 30 秒空闲对照：原 3 秒轮询 10 次完整状态拉取，当前 0 次；20 次通知合并为 1 次拉取。此为合成 IPC 对照，未换算成真实长期数据的耗时承诺。
- 发布输入扫描、格式与差异检查通过。
- 隔离全新安装、覆盖升级保留状态及本地提示词、二进制哈希一致、两次隐藏原生启动/IPC/托盘自检通过。实际安装包校验记录在构建目录生成，不纳入源码。

DSH 真实安装的原始首帧故障仍需现场确认；模拟启动器及协议测试通过不等同于该环境验证。未触碰正在运行的安装，也未发送真实模型推理请求。

补查上限的最终规则：增量分析结果继续采用；顶部明确提示“补查覆盖不完整”。归档必须完整覆盖材料，触及上限时不提交并保留归档游标。已将远端 test 的既有可靠性改动与本轮功能改动合并，保留其构建入口及历史验证记录。
