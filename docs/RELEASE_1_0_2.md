# 1.0.2 变更与验证

维护分支：test。安装包由同一份最终源码构建，沿用远端已合入的 Fluent 视觉与命令面板。

## 变更

- SS-046：实际处于工作中时，顶部和工作状态弹窗隐藏「开启加班」；加班中保留结束入口，日历和跨夜规则不变。
- SS-040：DSH 就绪检查区分 ACP profile 缺失、不可读、损坏与应用受限补丁缺失。缺少 profile 时显示当前启动器、DSH_HOME 对应的可复制 PowerShell 初始化命令，完成后可刷新模型重试；不再笼统建议手动添加模型。检测不自动初始化，不重置已有配置或凭据，受限配置校验继续生效。
- SS-047：AI 新增和编辑按实际数据差异判断失焦；无修改收起，有修改确认是否放弃，拒绝则保留草稿并阻止跳转。取消按钮直接丢弃，不重复确认；内部操作、模型删除、异步回调以及命令面板/快捷键导航共用保护。
- SS-048：修正复选框通用样式覆盖开关高度，圆点垂直居中；移除固定占位空档，保留消息过滤复选框及有序换行。减少动态效果设置也应用于圆点动画。
