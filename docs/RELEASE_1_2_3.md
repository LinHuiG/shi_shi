# 拾事 1.2.3

本版完善 AI 处置、事项记录查询和桌面同步，保留已保存的配置、消息与处理历史。

## 更新

- AI 处置使用独立的软件内窗口，固定标题和输入区，连续展示对话与结论。关闭后可重新打开，保留草稿、阅读位置和工具展开状态；命令与工具支持分组及单条两层折叠。
- 消息依据与事项变更记录使用浮窗，可组合关键词、排序和时间区间查询；分页、迟到响应与后台刷新保留当前事项范围和阅读状态。
- 默认列表统一为待处理事项，移除侧栏最近事项区；定时事项通过紧凑开关启停。事项变更通知缩小并支持整卡点击，关闭操作独立。
- 移除事项的单数 `next_step` 字段及对应编辑／输出协议，后续行动写入描述；旧数据仍可读取，报表的复数 `next_steps` 保留。升级不会用默认值覆盖用户自定义提示词。
- 桌面会话读取超限时使用有限的只读降级，保留已获取记录；按核实的会话及轮次回溯模型元数据，缺失时明确标记上次报告。
- 修正迟到成功／失败响应覆盖新追问、无变化同步重复保存、刷新丢失阅读状态及本地处置期间重启判断的问题。

## 发布检查

- 77 个变更文件逐行审查，源码按明确的允许清单打包；私人词汇、密钥及发布二进制中的个人构建路径检查通过。必要的第三方许可证与公开署名保留。
- Rust 工作区离线测试 621 项通过、6 项按既有规则忽略；47 套 UI 回归及 1 个 DSH 工作区桥接脚本通过。修正窄窗测试等待布局的时序，并将新增样式颜色统一为主题变量。
- Rust 首轮的通用工具回调用例出现一次失败，单项及完整工作区复跑通过；不据此声称穷尽所有并发情况。格式、发布检查器 5 项用例、离线更新分类及原生 `ss_tool` 回调检查通过。
- 全新隔离安装、从 1.2.2 升级、原生界面与通知检查通过。旧 JSON、SQLite、消息、事项、历史和自定义配置按场景检查保留；已移除事项字段不会重新写回。
- 外部 MCP 占用的隔离升级通过：只释放目标安装的辅助进程，其他安装继续服务；重新打开的桌面可阻止替换，升级后成功重启。
- 所有验证使用合成数据与模拟接入，未调用真实模型，未修改正在运行的安装。源码包不包含运行数据、私有配置、开发日志或构建目录。
