# 隐私与安全边界

## 数据会去哪里

来源插件把用户指定来源中的消息交给应用。分析会把选中的消息摘录、关联事项、规则和必要上下文发送给所选模型服务；按需图片也可能传输。正式处置可能通过用户已有的 Codex 工具访问项目或其他已授权服务。

AI 分析和处置可保存为 Codex 会话或 Harness 会话。模型服务、Codex/Harness 自身和远程工具有独立的数据保存规则；删除拾事本地文件不会自动删除这些副本。选择官方 OpenAI Chat Completions 兼容 API 时，选中的消息摘录、事项摘要和按需图片会发送到用户填写的 HTTPS 端点，由该服务按其规则保存。本项目不声称所有内容仅保留在本地，也不承诺完全离线运行。

## 本地位置

所有路径相对于安装目录：

| 路径 | 可能包含的内容 |
| --- | --- |
| `data/state.json`、`state.backup.json` | 消息、事项、来源配置、路由、提示词、临时/已归档记忆及历史记录，包括处置命令、工具参数和可见输出 |
| `data/ai-traces/` | 仅在开启完整跟踪时创建，包含输入、输出、事件和失败错误正文；关闭时不新建，旧目录按消息保留期清理 |
| `data/analysis-snapshots/` | 从源状态重建的只读消息、未归档事项和更新流水快照，可能包含完整消息正文及任务白名单字段（含长备注/描述）的变更文档；不含设置、提示词、凭据或日志正文；可随时删除并重建 |
| `data/ai-work/` 或指定分析工作目录 | Codex 分析会话整理文件；旧版本可能留下共享笔记，当前版本不导入也不使用 |
| `data/handling-context/` | 事项上下文授权、查询审计、短编号与原始编号的本地映射 |
| `data/logs/`、`data/reports/` | 操作及错误记录、报表 |
| `data/media/` | 图片缓存与摘要 |
| `data/credentials/` | DPAPI 加密的 API 密钥存储（仅当前 Windows 用户可解密）；环境变量方式不写入磁盘 |
| `data/holidays/` | holiday-cn 日历缓存、发布年份和获取时间；不含私人数据 |
| `data/tmp/` | 临时上下文；异常退出可能留下残余 |
| `data/plugins/`、`data/webview/` | 插件及其工作文件、WebView 用户数据 |

其他版本遗留的迁移文件、崩溃文件、外部备份也可能含敏感数据。不要通过上传整个目录来提交问题。

## 保留与清理

归档组、归档尝试、早报任务和工作日记录另按固定 90 天保留，仍被引用或未完成的记录除外。消息保留期默认 90 天：到期后原始消息、操作审计和已归档事项会压缩为不含原文的统计摘要（数量、类型、时间范围；过大时进一步压缩），`data/ai-traces/` 目录同时清理；仍被建议、提示词审阅或进行中处置引用的记录保留，未归档事项及其关联消息、归档游标之后的审计材料继续保留。`data/analysis-snapshots/` 不是独立保留数据，删除后由源状态重建。未归档事项、报表、历史提示词、旧备份及 Codex 会话不因此清除。关闭完整日志不会删除已经存在的历史日志。

应用退出后可备份自己需要的内容，再手动删除不需要的数据。版本不兼容时启动弹窗会列出具体的应用管理状态文件，用户确认后只清理列出的文件；取消会保留文件并停止加载。清理不会删除插件目录、外部来源配置、凭据、日志或报表。彻底重置本地应用需要处理整个 `data/`、用户另设的分析工作目录以及自行复制的备份；这会丢失事项和设置。还应在 Codex 或相应服务中独立处理会话副本。普通删除不保证存储介质上的不可恢复擦除。

安装器覆盖安装与卸载保留 `data/`，防止误丢工作记录；卸载不等于隐私数据清理。

## 插件与凭据

插件是与宿主同权限的本机 DLL，没有沙箱或崩溃隔离。包路径检查只能阻止路径穿越等打包问题，不能证明 DLL 安全。安装者必须审查来源。

`password` 配置字段只遮挡显示，并不提供加密。不要在普通配置中填写密码、API key 或长期令牌。官方 API 连接的密钥只能通过界面写入 DPAPI 本地存储，或指定一个环境变量名从进程环境读取；连接描述、状态、审计和日志只保留引用/是否配置，不保存或回显密钥。环境变量对其他同用户进程可见。需要认证的插件仍应使用 Windows 凭据库等独立安全存储，在普通配置中只存不敏感引用。不要把“进程内加密”宣传为对恶意插件的防护。

## 已有防护与剩余风险

已具备：默认关闭自动扫描；完整 AI 跟踪默认关闭；建议仅人工确认，系统提示词由用户配置，归档不再自动修改或采用提示词；固定协议独立拼入请求，不受记忆正文覆盖；插件路径与链接检查；输出 schema；只读快照的范围与单次响应大小限制；界面转义；版本比较和回滚；正式处置审批交互；私有已归档记忆仅保存在本地状态。

剩余风险：DLL 任意代码权限；私人数据可能出现在事项和错误记录中；持久 AI 会话另行保留；依赖和本地 IPC 需要持续安全审查；首轮调查边界主要由提示词表达，实际权限取决于 Codex 配置。当前没有宣称通过渗透测试、独立依赖审计或二进制安全认证。

默认提示词禁止将消息视作授权，但提示词不能单独消除注入风险。公开分享问题时，使用合成数据复现并检查截图、用户名、路径、账号和会话编号。
