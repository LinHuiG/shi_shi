# 1.0.4 设置自动保存与模型目录

维护分支：`test`。本次不修改个人提示词或正在使用的安装目录。

## 行为

- 设置页取消全局保存按钮：文本、数字和时间输入失焦保存，开关和选择项变更保存。字段补丁按顺序提交，后端基于最新配置校验并原子写入；无变化不写入。保存期间的新输入不被旧响应覆盖；错误保留输入并提供重试，未保存成功时阻止离开设置页。AI 连接独立编辑继续使用保存／取消。
- 保存状态区固定尺寸；更新保存提示不移动顶部扫描开关，顶部开关节点保持稳定。
- 合并远端已有的 Mica 背景与收件箱列表改动；背景开关一并接入自动保存，仍按原约定重启后生效。Mica 的实际系统材质效果保留原有现场验证边界。
- API 用途可选推理强度，默认省略 `reasoning_effort`。模型目录有能力声明时采用声明；缺少声明时提供标准兼容选项并提示能力尚未确认。所选参数在工具续轮和输出格式回退中保持一致，拒绝时报告错误，不暗中改用其他强度。
- 模型目录支持名称、编号、供应商关键词搜索，忽略大小写。全选／反选作用于可见结果，保留隐藏选择并显示数量；搜索不额外读取目录。
- DSH ACP 只继承桌面端内置 `llm-pi-ai` 供应商配置到应用拥有的临时补丁；同名模型保留不同供应商路由，展示源名称。显式 ACP 配置优先，不引入桌面 UI 插件，分析继续使用受限工具配置。检测、分析和处置使用相同供应商定义，原始配置不写回。

API 模型端点没有标准推理能力字段，不能仅凭模型名称保证兼容性。参数语义见 [官方 Chat Completions 文档](https://developers.openai.com/api/reference/resources/chat)；模型对象见 [官方 Models 文档](https://developers.openai.com/api/reference/resources/models)。供应商可能只支持部分选项。

## 验证边界

回归使用合成配置、模拟 API 传输和模拟 ACP，不调用真实模型。DSH 桌面与 ACP 的供应商配置差异通过只读检查确认；多供应商加载、同名路由、覆盖优先级、缺失和损坏配置、工具隔离通过离线验证。真实 DSH 的目录刷新与不同供应商推理仍需现场确认，不能把模拟结果视为真实调用已验证。

安装和覆盖安装验证使用独立目录，检查保存配置、本地提示词、日志、报表、插件文件保持不变；运行原生 WebView2、IPC、托盘启动检查。
