# 1.0.9 消息范围开关、记忆权限与日志用途筛选

维护分支：`test`。本轮测试均使用合成数据和模拟接入，没有调用真实模型，也没有覆盖运行中的安装或修改用户实际 DSH profile。

## 行为

- 新增“仅分析相关消息”开关，默认关闭。关闭时全部有效未分析增量按时间和输入预算装批；开启时沿用私聊、本人发送、被 @ 及已有事项关联会话规则。时间范围、撤回、已分析指纹和用量边界继续生效。切换不删除消息、不推进分析进度，“消息过滤”仍是独立的提前触发机制。
- 修复“安装 SS 会话插件”点击分发，并在安装过程中保留编辑器和进度。支持失败重试、成功提示及重启 DSH 说明；打开设置只检查状态，不自动安装。
- 临时记忆采用自主工作区说明，可记录线索、未决问题、用户倾向或其他需要交接的内容；不强制每轮更新。说明及完整读取/整份替换/2000 字符/并发保护协议直接拼入实际系统提示词段，独立于用户可编辑提示词与 AI 可修改的记忆正文。
- 系统提示词仅由用户配置或手动采用，版本与回滚保留。新增“归档与记忆”提示词配置入口。取消归档自动替换/采用提示词、跨日自动启用建议及归档规则、处置策略、标签目录维护；旧自动开关仅兼容读取，已不生效且不再展示。
- 消息分析维护临时记忆；归档只维护私有归档记忆，同时继续生成报表和归档事项。归档不再覆盖或清空临时记忆。归档输出 schema 精简为 `report` 和 `memory_changes`，提交路径也不接受旧输出的策略副作用；旧提示词、标签、建议和历史不静默清理。
- 日志入口改为“AI 记录”，用途可选全部、AI 分析、消息过滤、报表、归档。服务端在计数和分页前筛选，保留日期及选中用途，防止异步旧响应覆盖新选择；宽屏与窄窗口沿用现有深色样式。
- 消息过滤的开始、完成、失败、中断和超限单独命名；过滤提前触发与过滤失败回退不再误记为“分析间隔触发”。手动分析仍重置间隔，体积阈值或消息过滤可提前执行，未改变该调度机制。
- 修复“事项变更”发送错误筛选参数导致日志加载失败。前端统一使用 `changes`，后端兼容旧 `tasks` 别名。
