# 1.0.3 变更与验证

维护分支：test。由统一校验后的最终代码构建，不包含私人运行数据。

## 变更

- AI 新增/编辑中，点击标题、模型目录与内部空白不再误触发离开确认；区域外点击、Tab 离开及取消规则保持。
- 缺少 DSH ACP profile 时显示「初始化 ACP 环境」。用户明确确认后，以所选启动器和同一 DSH_HOME 初始化内置 profile，完成后检查受限配置并自动读取模型。无需第三方插件；已有损坏或不可读配置不覆盖、不重置凭据。配置导出模式的初始化语义参考 [官方 CLI 说明](https://github.com/deepseek-ai/deepseek-harness/blob/dsh-v0.2.1-rc.2/apps/cli/reference/README.md)。
- 模型目录可逐项勾选、全选和反选，显示已选数量；只保存所选模型，同名模型保留来源及完整路由，全部取消时明确提示至少选一个。
- 日志页按日期与类型查询磁盘日志（含轮转），筛选后分页，避免最后 60 条扫描把早间 AI 分析遮住；支持上一页/下一页、读取失败重试和损坏行计数。
- 临时记忆改为 AI 自主维护的自由工作区，可给下一轮和下一独立线程交接，取消稳定/可复用经验门槛。整份仍限 2000 字符，超限拒绝且保留旧记忆，不截断；原有并发保护和归档清理机制保持。
