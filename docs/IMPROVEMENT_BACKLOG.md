## PUB-001 YAML 解析依赖的维护状态

- 证据：发布依赖比对发现 `shishi-acp → serde_yaml_ng → unsafe-libyaml 0.2.11`；RustSec 将末端依赖标记为停止维护（[RUSTSEC-2024-0449](https://rustsec.org/advisories/RUSTSEC-2024-0449.html)）。这是一项维护提示，本次比对没有发现 Windows 目标的适用漏洞公告。
- 范围：调查可维护的 YAML 解析替代方案及 ACP 配置兼容性，不因登记而自动替换依赖或改写用户配置。
- 验收：验证受限配置合并、模型目录、Unicode、无效输入和失败保留行为，更新锁文件并重新核对依赖公告及许可证。

- 验收：覆盖 760px 与 360px 宽度及完整事项交互套件，超时仍报告失败。

维护分支以当前检出仓库的 `AGENTS.md` 为准：公开发布检出使用 `main`，私有开发检出使用 `test`。
