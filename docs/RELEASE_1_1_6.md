# ShiShi 1.1.6

本版处理 SS-112—SS-114，修正上一版的编辑回传、过滤交接与游标推进回归。

- 修复人工“保存事项”及“AI 分析并更新”因快照展示字段 evidence_count 无法反序列化。计数仅用于显示，不进入持久化 Task；保留未知业务字段拒绝、并发校验和编辑语义。
- 有效的新过滤决定直接交接完整分析，不再等待上一轮分析结束后的常规 60 秒冷却；忙碌、时段、预算、配额及取消保护保留，同一决定仍只消费一次。没有新决定时继续遵守常规分析间隔及冷却。
- 过滤/分析游标推进至最新已确认的消息版本，已分析消息同步纳入过滤进度。范围外或其他真正未处理的空洞保留独立版本例外，不误标成功；范围外旧消息不再把两个游标卡在零，扩大回看、重启后仍能找到这些消息。并发新到消息不被旧批次完成覆盖。
- 扫描与 AI 继续独立运行：分析采用冻结输入，运行中扫描读到的新消息进入下一批；日志中的扫描行数含回查，并非新增条数。本轮未修改扫描间隔设置或将扫描绑定到 AI 忙碌状态。

验证：Rust 离线 470 项通过、7 个既有忽略、0 失败；格式检查及全部 20 套 UI 回归通过。新增真实快照形状的人工保存/AI 修改入口测试、未知业务字段拒绝、过滤决定即时交接/消费后不重复、范围外空洞/扩大回看/重启，以及分析期间新消息保护。

全新 /TEST 隔离安装的文件清单、启动、IPC、托盘和退出自检通过；安装 EXE 与 release EXE SHA256 一致。源码白名单、敏感模式扫描及人工变更审查通过。全部测试使用合成数据和模拟接入，不修改运行中的安装或私人设置，不调用真实模型。
