# 1.1.1 流式 AI 进度、统一期限与布局稳定性

维护分支：`test`。全部回归使用离线模拟接入和合成数据；不调用真实模型，不覆盖运行中的安装，不修改实际 DSH profile。

## 行为

- 保留工具名称、参数及权限的严格校验。已知只读工具参数格式错误最多纠正一次，该批工具在全部参数通过验证前不执行；纠正、工具循环及输出格式处理共享总时限。
- DSH 可识别的 refusal 与 API 拒答明确显示“供应商拒答”；未知内部错误仍保持未知。504 单独说明为上游网关超时；适配器不因拒答、504、断流或未知提交结果自动重发整轮。
- 开启“保留完整 AI 跟踪”时，原始供应商响应和工具参数校验失败详情保存在本地调用详情，屏蔽当前 API 密钥及图片数据。工具失败单独留存，不受普通事件流长度上限遮挡；关闭跟踪时不保存这些正文。
- 设置“扫描与分析 → AI 请求高级选项”新增一个全局 AI 总时限，默认 600 秒，范围 30—1800 秒。Codex、DSH、API 的结构化分析请求共用，不按来源或连接分别配置。旧配置缺少该字段时采用 600 秒，原有提示词、连接及历史保留。
- 前端长操作先取得操作编号，再追踪同一操作的最终结果与取消；不再因通用 IPC 等待 300 秒结束而误报后台 AI 已失败，查询状态不重复提交原操作。
- API 默认流式读取响应，连接高级选项可明确关闭；处理 UTF-8/SSE 分片、公开思考内容、工具参数拼接和末尾用量。DeepSeek 工具回合按协议保留 reasoning_content；DSH 接入公开思考片段，Codex 沿用实际公开事件。
- 底部原有单行显示模型、阶段、已用时及最近收到内容时间，空间不足时截断。点击展开有界实时详情，保留用户滚动位置；新请求不会覆盖正在查看的旧请求预览。半截响应和工具参数不应用到业务数据。
- 日志日期、数量及分页在宽度足够时与筛选及用途合并一行，窄窗口自然换行。稳定滚动条占位、统一提示词页签及加载占位宽度，修复日志筛选、提示词页签和消息依据展开时不变区域的轻微位移。
- 底部状态和等待分析入口垂直对齐，移除数量后的上箭头；点击打开待分析管理及取消 AI 的行为保留。
