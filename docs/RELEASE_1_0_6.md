# 1.0.6 Mica 浅底与文字对比度修复

分支：`test`。

## 结果行为

- 原生窗口采用完整客户区 DWM frame 与黑色合成基底，不再混用旧式透明窗口 blur。深色标题栏与 Mica 初始化都检查结果；WebView 明确设置深色主题，仅在原生初始化成功后透明。
- 页面在 Mica 下保留深色保护层。即使系统底层错误显示白色，侧栏仍为深色，内容区维持深色层级，常规辅助文字对比度不低于 4.5:1。关闭毛玻璃、初始化失败或运行时刷新失败都恢复不透明深色。
- 窗口激活／失焦与缩放时重新扩展合成 frame。系统强制颜色与减少透明度偏好仍保留既有回退。

原生处理参考 [Microsoft DWM 自定义窗口框架](https://learn.microsoft.com/en-us/windows/win32/dwm/customframe) 中完整客户区扩展、激活时更新及黑色背景的合成要求。保护层独立于原生材质是否正常工作。

## 验证

- 410 项 Rust 测试通过，7 项按原有条件忽略，0 失败；16 套 UI 回归通过。新增回归验证白色原生底层下的保护层和辅助文字对比度、亮暗偏好、窗口尺寸及强制颜色。
- 本机真实原生窗口验证：Mica 开启（报告 `mica=true`）与强制初始化失败（`mica=false`）均完成客户区截图、窗口缩放和关闭到托盘／托盘退出检查。人工检查截图未见浅底浅字。普通不透明原生自检另通过两次。
- 全新安装、覆盖安装及旧分类转换检查通过，配置、数据、本地提示词、日志、报表与插件文件保留。
- 改完代码后已先同步远端 `test` 再 review、统一验证和打包；隐私与发布输入检查通过。全部使用隔离合成数据，不修改用户安装，不调用真实模型，不修改系统主题与透明设置。其他 Windows 版本、显示缩放比例和系统透明／节电组合未现场验证。
