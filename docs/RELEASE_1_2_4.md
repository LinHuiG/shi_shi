# 拾事1.2.4

本版增加命令行入口和事项关注分类，完善批量分析、归档记忆、插件隔离及安装升级，并合并重复实现。升级保留已保存的个人配置、提示词和业务数据。

## 更新

- 新增ss.exe命令行入口，与图形端共用后台、业务校验和保存流程；两端分别管理常驻状态，支持事项、记忆、查询与数据目录迁移。
- 关注区分为待处理、处理中、被阻塞和延后处理。延后事项按恢复时间排序，原本处理中的事项到期恢复原状态；完成事项保留截止日期并取消逾期提醒。
- 分析按完整请求体积连续处理积压，普通失败保留后续自动重试，命令结果未知时继续阻止重放。结构完整但空动作、空结论的结果经过一次纠正后可降级接收，并明确记录系统标记。
- 修复重复新建转为更新后，同批后续有效动作被误判为版本冲突；保留外部并发、人工修改、证据与原子保存检查。标签修改使用明确的增删动作，空集合不会清除已有标签。
- 归档记忆改为最多4000个Unicode字符的整段文本，旧内容完整保留；人工编辑与归档共用版本及完整读取检查，临时记忆保持独立。
- 来源采集和配置共用可终止的插件工作进程，隔离致命崩溃并支持超时、取消与后续重建；进程隔离不限制插件的文件或网络权限。
- 合并模型工具循环、状态投影、JSON计量和测试准备，移除闲置共享快照及中间适配，使用可复用连接的HTTP实现；保留HTTPS、证书校验、总期限和取消边界。
- 修复接入路径切换、受管CLI更新后的路径恢复、刷新竞争、汇总状态、会话短编号补查及列表闪动。NSIS文件释放失败时返回失败并保留原版本标记。

## 兼容与验证范围

个人提示词不会被新的默认模板覆盖。旧配置、事项、消息与历史按现有迁移协议保留；安装包包含主程序、CLI、必要依赖及文档，不含私人插件或运行数据。

本地准备阶段不推送代码或发布远端资源。隐私检查、完整离线回归、安装升级与产物校验的本轮结果保存在随包交付记录中；离线合成测试不代表真实模型、企业代理或所有Windows环境均已验证。源码减少不代表安装包缩小或整体性能提升。
