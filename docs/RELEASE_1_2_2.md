# 1.2.2 更新说明

本次更新延续公开版本的许可证、更新地址和数据保留规则。

- 注册工具统一由拾事校验、执行和记录。非处置的 Codex、DSH 与 API 共用工具循环；处置通过已有事项凭证使用通用 `ss_tool`。工具配置由用户维护，输入资料与工具输出不会授予额外权限。
- 工具记录支持按事项关联、搜索、分页和逐条查看。整理工具设置、复制及弹窗返回，事项状态操作合并到完成按钮菜单，标签编辑保留人工选择。
- 消息来源插件可声明独立的本地 HTML 配置页。页面通过校验过的方法桥访问插件自身配置，不附带任何专用聊天工具适配器或账号数据。
- 业务状态改用 SQLite，保留旧 JSON 原件，并在迁移失败时停止替换程序。大集合使用共享快照，减少无变化复制；升级保留已有提示词、模型、消息和事项。
- 事项变更可显示紧凑通知，通过简短摘要打开对应事项。补充插件设置、通知、存储迁移及工具循环的离线回归。
- 关于页面的文档和介绍入口统一指向公开项目；源码不包含个人博客链接、私有仓库历史、开发交付记录或运行数据。
- 发布构建映射源码和工具链路径，避免程序的报错定位字符串暴露构建账户目录。

验证范围以本次实际运行的离线检查为准；不将模拟供应商测试称为真实模型兼容性验证。

本版验证：Rust 工作区离线回归 607 项通过、6 项既有忽略；46 套 UI／工作区桥检查通过。事项菜单测试显式等待鼠标离开再进入，避免状态刷新重建按钮后的悬停时序误报。发布边界的 5 项用例、原生工具桥、安装器参数和下载元数据分类检查通过；暂存差异与完整源码的 Gitleaks 扫描均无命中，专用隐私词典检查通过。隔离的全新安装、1.2.1 升级、WebView 与原生通知验收通过，原 JSON、合成消息、事项和配置保留，SQLite 完整性检查通过。

依赖维护提示：`unsafe-libyaml 0.2.11` 有[停止维护公告](https://rustsec.org/advisories/RUSTSEC-2024-0449.html)，跟进范围记录在 `PUB-001`。本次公告比对未发现影响 Windows 目标的已公布漏洞；锁文件中其他平台的既有告警不作为已修复。本版只发布 Windows x64 安装包。
