拾事 ShiShi

拾事是Windows桌面AI事项助手：把聊天消息整理成可跟进的事项，
保留消息依据和处理经验，由你选择事项交给AI调查、处置并查看结果。

主要功能
- 插件读取消息、增量导入、去重和收件箱查询。
- AI整理或手动创建事项，维护状态、等级、截止时间、标签与定时事项。
- 定时分析、早报、下班汇总、归档，以及可查看和编辑的AI记忆。
- AI一键处置：用所选模型在Codex或DSH中开始调查并交给客户端继续，进展经CLI写回事项。
- 提示词、规则与标签建议由你预览和采用。
- 插件独立配置页、事项变更提醒和SQLite业务数据存储。

开始使用
1. 准备Windows x64和Microsoft Edge WebView2 Runtime。
2. 在设置中配置AI连接与用途模型。Codex CLI支持分析，Codex桌面端执行处置；
   DeepSeek Harness（ACP）支持分析和处置，兼容HTTPS API支持分析。
3. 可先手动创建事项。需要消息时，在“消息来源”安装可信插件并配置数据位置。
   用途模型留空时不调用模型；完整AI跟踪默认关闭。

数据与运行
消息、事项和配置保存在本机；调用AI时会发送相关内容给所选后端。
插件在独立的工作进程中运行，请只安装可信插件，仅读取已授权的数据。
API密钥使用Windows DPAPI保存，或从指定环境变量读取。
自动任务需要后台保持运行；关闭窗口进入托盘，托盘菜单“退出”释放图形端。
开启自动更新后，每天凌晨04:00自动安装已下载的新版本并重启，无需手动退出。
届时需保持电脑和拾事运行，错过不补执行。手动覆盖安装可选择强制退出拾事及后台。
shishi.exe同时是命令行入口：运行 shishi.exe --help 查看命令，详细说明见CLI.md。
让agent读取skills/shishi-cli/SKILL.md即可了解CLI用法。
