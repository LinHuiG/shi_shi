# 通用 JSON 消息来源

这是完整的协议示例，读取用户指定的 UTF-8 JSON 文件。它不连接任何私人服务，不包含真实消息。

消息文件格式：

```json
{
  "messages": [
    {
      "id": "demo-1",
      "chat": "demo-room",
      "sender": "示例协作者",
      "time": 1792137600000,
      "text": "请确认下周讨论会的议程。",
      "private": true,
      "mine": false
    }
  ]
}
```

`time` 为毫秒时间戳；演示时换为当前时刻，否则可能超出回看或保留窗口。每条消息需要稳定非空 ID 和正时间戳。示例限制文件为 24 MiB；`scan_root` 只检查给定目录的有限直接子项，不递归扫描整台电脑。

在仓库根目录构建示例包，将 `target/release/shishi_json_source.dll` 与此目录的 `plugin.json` 放入空文件夹并压成 ZIP。主安装器不自动安装该插件。通过“消息来源”安装，选择消息文件，验证后启用。

仅文件路径也可能暴露个人目录，不要把已填写的插件配置当作公共示例。示例采用主项目 [GNU AGPL v3.0](../../LICENSE)（`AGPL-3.0-only`，仅 3.0 版）；生产适配请实现更严格的资源限制、并发和错误处理。
